# varicent-kit-2

Varicent UI design-system kit for **Figma Make** — v2. AI reads `guidelines/` markdown to enforce the design system when generating UI.

## Contents

| Path | Purpose |
|------|---------|
| `guidelines/Guidelines.md` | Tokens, typography, 30 ICM components, AI generation rules |
| `guidelines/icon-registry.md` | Semantic action → verified icon export (80+ mappings) |
| `guidelines/component-patterns.md` | Per-component battle-tested usage rules |
| `guidelines/component-notes.md` | Session-learned fixes with Don't/Do examples |
| `guidelines/setup.md` | Kit setup, required deps, anti-patterns |
| `docs/make/CONTRIBUTING.md` | How to add rules via Make chat → PR → publish |

## Publishing

Published as `@make-kits/varicent-kit-2` via the Figma Make Kit UI. See `docs/make/CONTRIBUTING.md` for the living knowledge workflow.
